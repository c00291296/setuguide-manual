SETU GUIDE APP MANUAL

Introduction

Withing this web manual, the user is instructed how to use the SETU Guide App. The app is pretty simple and straightforward, and thus doesn't require much explanation.

System Requirements

The application requires an Android device. The least Android version allowed is 10. The device must have network capability, GPS and a screen.

Installation

Just download and install the apk to get started with the application.

Accessing the guidebook

In order to access the guidebook, click the first option on the menu. Then, you are free to view the variety of articles that have been uploaded into the application.

Navigating the maps

Navigate the respective menu option to go to the maps. You will be presented with a map, where all the walls identified by the program as impassable will be identified in blue. Double tap on a location to find the path to there.
